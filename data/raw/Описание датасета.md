# NHL Dataset — Описание данных

## Общая информация

| Параметр | Скейтеры                | Вратари                 |
|---|-------------------------|-------------------------|
| Файл | `nhl_skaters_raw.csv`   | `nhl_goalies_raw.csv`   |
| Строк | 4748                    | 525                     |
| Колонок | 90                      | 46                      |
| Сезоны | 2021-22 → 2025-26       | 2021-22 → 2025-26       |
| Тип игр | Только регулярный сезон | Только регулярный сезон |

## Источники данных

| Источник | Что содержит |
|---|---|
| `api.nhle.com/stats/rest/en` | Игровая статистика (все статистические колонки) |
| `api-web.nhle.com/v1/player/{id}/landing` | Биография: рост, вес, город рождения, страна, информация о драфте |
| `spotrac.com` | Зарплата игрока (cap hit) |

## Скейтеры — описание колонок

### Идентификация игрока
| Колонка | Описание |
|---|---|
| `playerId` | Уникальный ID игрока в NHL API |
| `skaterFullName` | Полное имя игрока |
| `lastName` | Фамилия |
| `positionCode` | Позиция (C, L, R, D) |
| `shootsCatches` | Хват клюшки (L / R) |
| `teamAbbrevs` | Аббревиатура команды(команд) в сезоне |
| `season` | Сезон в формате XXXXXXXX (напр. 20212022) |
| `seasonId` | ID сезона (дубль season из API) |
| `season_year` | Год окончания сезона (напр. 2022) |
| `name_key` | Нормализованное имя для джоина (строчные буквы, без диакритики) |

## Примечания

- Около 30-35% игроков не имеют `cap_hit` — это игроки на двусторонних контрактах (AHL/NHL) или те кого нет на Spotrac
- `draftYear` и `draftOverall` могут быть пустыми — не все игроки были задрафтованы (подписаны как свободные агенты)
- Один игрок может встречаться несколько раз — по одной строке на каждый сезон
- Если игрок играл за несколько команд за сезон, `teamAbbrevs` содержит все команды через запятую
